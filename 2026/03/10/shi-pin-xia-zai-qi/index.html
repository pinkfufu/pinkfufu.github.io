视频下载器：基于 FastAPI + yt-dlp 的网页实现视频下载

FastAPI yt-dlp
技术实践
发布日期:   2026-03-10
更新日期:   2026-03-12
文章字数:   1.6k
阅读时长:   7 分

通过 Python 的 FastAPI 框架，将 yt-dlp 的核心能力封装为 Web 服务，实现了从链接粘贴到本地保存的全流程自动化。

🚀 核心功能

  • 全平台支持：基于 yt-dlp，支持 YouTube, Bilibili 等网站。
  • 实时进度条：前端轮询后端状态，实时显示下载百分比。
  • 风控绕过：集成 Netscape 格式 Cookie 支持，规避机器人检测。
  • 自动合并：利用 FFmpeg，自动将分离的高清视频流与音频流合并为 MP4 格式。
  • 异步任务处理：使用多线程模型，下载过程中 Web 服务依然响应敏捷，不阻塞主线程。

🛠️ 技术实现要点

1. 异步下载处理

由于视频下载是典型的耗时操作，直接在 FastAPI 路由中执行会导致连接超时。

采用 threading.Thread 将下载任务丢入后台，并使用全局字典 download_tasks 维护任务状态，将下载任务丢入后台线程：

# 核心逻辑：启动后台线程
@app.get("/start_download")
def start_download(url: str):
    task_id = str(uuid.uuid4())
    download_tasks[task_id] = {'status': 'downloading', 'progress': 0}
    threading.Thread(target=download_worker, args=(url, task_id), daemon=True).start()
    return {"task_id": task_id}

2. 进度反馈机制

利用 yt-dlp 提供的 progress_hooks 接口，我们可以实时获取下载字节数，将进度限制在 99%，预留 1% 给最后的 FFmpeg 合并阶段，供前端通过 AJAX 请求轮询。

def ydl_progress_hook(d, task_id):
    if d['status'] == 'downloading':
        total = d.get('total_bytes') or d.get('total_bytes_estimate') or 100
        downloaded = d.get('downloaded_bytes', 0)
        percent = int(downloaded / total * 100)
        download_tasks[task_id]['progress'] = min(percent, 99) # 留 1% 给合并

3. 环境依赖 (重要)

要实现 1080P 以上画质的下载，必须确保系统中安装了 FFmpeg。

  • Windows: 下载 ffmpeg.exe 并加入系统 Path。
  • Linux: sudo apt install ffmpeg

4.克隆项目与安装环境

本项目代码已开源，GitHub 仓库: video-downloader-fastapi

💻 核心代码实现

以下是经过优化的 main.py 完整代码，包含 Cookie 自动检测逻辑：

from fastapi import FastAPI, HTTPException
from fastapi.responses import HTMLResponse, FileResponse
import yt_dlp
import tempfile
import os
import threading
import uuid

# 安装环境：conda create -n venv_downloader python=3.10 -y && conda activate venv_downloader && pip install fastapi uvicorn yt-dlp "numpy<2"
# 启动命令：uvicorn main:app --host 0.0.0.0 --port 8000
# 警告：不要在开发环境下频繁保存代码触发 reload，否则会导致内存中的 download_tasks 任务丢失报错 404。

app = FastAPI()

# 全局任务字典 (生产环境建议使用 SQLite 或 Redis)
download_tasks = {}

COOKIES_FILE = "cookies.txt"


def download_worker(url, task_id):
    # 使用系统临时目录下的子文件夹，避免权限问题
    temp_dir = os.path.join(tempfile.gettempdir(), "video_downloads", task_id)
    if not os.path.exists(temp_dir):
        os.makedirs(temp_dir)

    output_tmpl = os.path.join(temp_dir, '%(title)s.%(ext)s')

    ydl_opts = {
        'outtmpl': output_tmpl,
        'format': 'bestvideo[ext=mp4]+bestaudio[ext=m4a]/best[ext=mp4]/best',
        'merge_output_format': 'mp4',
        'quiet': True,
        'no_warnings': True,
        'progress_hooks': [lambda d: ydl_progress_hook(d, task_id)],
        'user_agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/122.0.0.0 Safari/537.36',
    }

    # Cookie 逻辑优化
    cookie_path = os.path.join(os.getcwd(), COOKIES_FILE)
    if os.path.isfile(cookie_path):
        ydl_opts['cookiefile'] = cookie_path
    else:
        # 针对 Windows，尝试从浏览器提取
        ydl_opts['cookiesfrombrowser'] = ('chrome',)

    try:
        with yt_dlp.YoutubeDL(ydl_opts) as ydl:
            # 获取视频信息并执行下载
            info = ydl.extract_info(url, download=True)
            # 获取最终生成的本地文件绝对路径
            final_path = ydl.prepare_filename(info)

            # 处理可能的格式转换后缀变化
            if not os.path.exists(final_path):
                # 尝试检查 .mp4 结尾
                base_path = os.path.splitext(final_path)[0]
                if os.path.exists(base_path + ".mp4"):
                    final_path = base_path + ".mp4"

            download_tasks[task_id]['status'] = 'finished'
            download_tasks[task_id]['filename'] = final_path

    except Exception as e:
        download_tasks[task_id]['status'] = 'error'
        error_msg = str(e)
        if "ffmpeg" in error_msg.lower():
            error_msg = "系统未安装 FFmpeg，无法合并音视频。请安装 FFmpeg 并添加到环境变量。"
        download_tasks[task_id]['error'] = error_msg


def ydl_progress_hook(d, task_id):
    if d['status'] == 'downloading':
        total = d.get('total_bytes') or d.get('total_bytes_estimate') or 100
        downloaded = d.get('downloaded_bytes', 0)
        percent = int(downloaded / total * 100)
        # 限制最高 99%，留 1% 给合并阶段
        download_tasks[task_id]['progress'] = min(percent, 99)
    elif d['status'] == 'finished':
        download_tasks[task_id]['progress'] = 100

@app.get("/start_download")
def start_download(url: str):
    task_id = str(uuid.uuid4())
    download_tasks[task_id] = {'status': 'downloading', 'progress': 0, 'filename': None, 'error': None}
    threading.Thread(target=download_worker, args=(url, task_id), daemon=True).start()
    return {"task_id": task_id}


@app.get("/progress")
def get_progress(task_id: str):
    task = download_tasks.get(task_id)
    if not task:
        # 如果重启了，这里会报 404
        return {"status": "error", "progress": 0, "error": "任务已失效（服务器可能已重启）"}
    return task


@app.get("/download_file")
def download_file(task_id: str):
    task = download_tasks.get(task_id)
    if not task or task['status'] != 'finished' or not task['filename']:
        raise HTTPException(status_code=404, detail="文件不存在")

    # 真正的文件名
    real_name = os.path.basename(task['filename'])
    return FileResponse(
        path=task['filename'],
        filename=real_name,
        media_type='application/octet-stream'
    )
