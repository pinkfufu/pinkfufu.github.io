🛠️ 常用运维脚本汇总：跨平台工具箱

本博文记录了我在实际工作中经常使用的脚本。所有脚本均经过实测，能够有效提升工作效率。

一、 Windows 平台工具 (CMD/BAT)

这些脚本基于 Batch (批处理) 编写，适用于 Windows 系统，保存为 .bat 后缀。

1. Nginx 进程管理工具 (NgControl.bat)

  • 脚本类型：Windows Batch
  • 用途：提供菜单化界面，一键查找 Windows 环境下的 Nginx 进程，并支持强制终止进程，解决 Nginx 重启失败的问题。

代码段

@echo off
chcp 65001 >nul
title Nginx windows环境查杀工具

:MENU
cls
echo ===============================
echo        Nginx 管理工具
echo ===============================
echo 1. 查找 nginx 进程
echo 2. 终止 nginx 进程
echo 3. 退出
echo ===============================
set /p choice=请选择操作 [1-3]： 

if "%choice%"=="1" goto FIND
if "%choice%"=="2" goto KILL
if "%choice%"=="3" exit
goto MENU

:FIND
cls
echo 正在查找 nginx 进程...
echo --------------------------------------
tasklist | findstr /i "nginx"
echo --------------------------------------
echo.
pause
goto MENU

:SHOWPORT
cls
echo nginx PID: %PID%
echo --------------------------------------
echo 正在查询端口信息...
netstat -ano | findstr "%PID%"
echo --------------------------------------
echo.
pause
goto MENU

:KILL
cls
echo 正在查找 nginx 进程...
tasklist /fi "imagename eq nginx.exe"
echo.
echo 正在结束 nginx 进程...
taskkill /fi "imagename eq nginx.exe" /F
echo.
echo 操作完成！
pause
goto MENU

2. 端口占用杀手

  • 脚本类型：Windows Batch
  • 用途：输入端口号即可自动识别并结束占用该端口的 PID 进程，常用于释放被占用的 80、8080 等端口。

代码段

@echo off
chcp 65001
set /p port=请输入端口号:
for /f "tokens=5" %%a in ('netstat -ano ^| findstr "%port%"') do (
    taskkill /PID %%a /F
)

3. 微信多开脚本

  • 脚本类型：Windows Batch
  • 用途：快速启动两个微信进程。注意：请根据实际安装路径修改代码中的目录。

二、 Linux 平台工具

针对 Linux 环境（以 Ubuntu 24.04 为主）的系统优化与配置脚本。

1. 系统别名配置 (Alias)

  • 脚本类型：Bash 配置
  • 用途：在 /root/.bashrc 中定义常用命令的缩写，极大简化 Docker 操作和系统清理操作。

代码段

# 修改/root/.bashrc文件
vi /root/.bashrc
# 修改/root/.bashrc文件
vi /root/.bashrc

# 修改/root/.bashrc文件后执行 source /root/.bashrc 生效
alias rm='rm -i'
alias cp='cp -i'
alias mv='mv -i'
alias cls='clear'
# 简化 Docker 常用查看命令
alias dps='docker ps --format "table {{.ID}}\t{{.Image}}\t{{.Ports}}\t{{.Status}}\t{{.Names}}"'
alias dis='docker images'
alias dexe='docker exec -it'
alias dlog='docker logs'

# Source global definitions
if [ -f /etc/bashrc ]; then
        . /etc/bashrc
fi
# 然后，执行命令使别名生效
source /root/.bashrc

2. 虚拟内存 (Swap)

  • 脚本类型：Bash 指令
  • 用途：为内存较小的服务器增加 4GB 虚拟内存，并优化 swappiness（设置为 80），提高系统稳定性。

代码段

# 1. 创建4GB的交换文件
fallocate -l 4G /swapfile

# 如果fallocate不可用，使用以下命令（会稍慢）：
# dd if=/dev/zero of=/swapfile bs=1M count=4096

# 2. 设置权限
chmod 600 /swapfile

# 3. 格式化
mkswap /swapfile

# 4. 启用
swapon /swapfile

# 5. 永久生效：将交换文件信息添加到fstab
echo '/swapfile none swap sw 0 0' >> /etc/fstab

# 6. 验证
free -h

# 查看当前swappiness
cat /proc/sys/vm/swappiness

# 临时设置为80
sysctl vm.swappiness=80

# 永久生效
echo 'vm.swappiness=80' >> /etc/sysctl.conf
sysctl -p

三、 Docker 自动化工具 (Shell/Bash)

0.上传脚本后先进行赋权

  • 赋予执行权限：Linux 系统默认不允许直接运行上传的文件。chmod +x 是给文件添加“可执行”权限。
  • 丢入后台运行 (核心)：**2>&1：将错误信息也一并写入日志，防止脚本报错你却不知道，&**：让脚本在后台运行，这样你可以继续在终端输入其他命令。
chmod +x pull_images.sh
nohup ./pull_images.sh > pull_images.log 2>&1 &
ps -ef | grep pull_images.sh

1. 容器日志清理脚本

  • 脚本类型：Shell (/bin/sh)
  • 用途：Docker 容器运行久了产生海量日志，该脚本可安全清空 /var/lib/docker/containers/ 下的所有 .log 文件。
#!/bin/sh 
echo "======== start clean docker containers logs ========"  
logs=$(find /var/lib/docker/containers/ -name *-json.log)  
for log in $logs  
        do  
                echo "clean logs : $log"  
                cat /dev/null > $log  
        done  
echo "======== end clean docker containers logs ========"

2. 镜像批量拉取 (pull_images.sh)

  • 脚本类型：Bash
  • 用途：一键部署常用中间件环境（MySQL、Redis、Nacos、Jenkins 等。
#!/bin/bash

# 定义要拉取的镜像列表
IMAGES=(
    elasticsearch:7.12.1
    kibana:7.12.1
    gogs/gogs:0.12
    jenkins/jenkins:2.361.1-lts-jdk11
    nacos/nacos-server:v2.1.0-slim
    openjdk:11.0-jre-buster
    rabbitmq:3.8-management
    redis:latest
    xuxueli/xxl-job-admin:2.3.0
    mysql:8.4.7
    mongo:latest
    imaegoo/twikoo:latest
    minio/minio:RELEASE.2025-04-22T22-12-26Z
    dko0/lsky-pro:latest
    seataio/seata-server:1.5.2
    nginx:1.13.8
)

echo "--- 📥 开始批量拉取 Docker 镜像 ---"

for IMAGE in "${IMAGES[@]}"; do
    echo "---"
    echo "正在拉取: ${IMAGE}"
    
    # 执行 docker pull 命令
    docker pull "$IMAGE"
    
    if [ $? -eq 0 ]; then
        echo "✅ ${IMAGE} 拉取成功."
    else
        echo "❌ ${IMAGE} 拉取失败. 请检查网络连接或镜像标签是否正确."
    fi
done

echo "--- 🎉 所有镜像拉取任务完成 ---"

3. 镜像批量打包 (save_all_images.sh)

  • 脚本类型：Bash
  • 用途：用于“有网”和“无网”环境的镜像中转。支持批量拉取常用镜像清单，并能一键将本地所有有效镜像打包为 .tar 文件。
#!/bin/bash

# --- 配置 ---
# 定义保存文件的目录。默认保存到当前目录下的一个新文件夹
SAVE_DIR="docker_images_backup"
LOG_FILE="${SAVE_DIR}/packing_log_$(date +%Y%m%d_%H%M%S).log"

# 创建保存目录（如果不存在）
mkdir -p "${SAVE_DIR}"

echo "--- 🚀 开始打包本机所有 Docker 镜像到 .tar 文件 ---"
echo "保存目录: $(pwd)/${SAVE_DIR}"
echo "日志文件: ${LOG_FILE}"

# 将所有输出重定向到日志文件，并在终端打印关键信息
exec > >(tee -a "$LOG_FILE") 2>&1

echo "$(date): 脚本开始执行"
echo "---"

# 1. 获取本机所有镜像的列表 (REPOSITORY:TAG)
# 排除掉 <none>:<none> 的悬空镜像
IMAGES=$(docker images --format '{{.Repository}}:{{.Tag}}' | grep -v 'none:none')

# 将多行字符串转换为 Bash 数组
IFS=$'\n' read -r -d '' -a IMAGE_ARRAY <<< "$IMAGES"

# 检查是否有镜像需要打包
if [ ${#IMAGE_ARRAY[@]} -eq 0 ]; then
    echo "$(date): ⚠️ 警告：未发现有效的本地 Docker 镜像需要打包。"
    echo "--- 🎉 脚本结束 ---"
    exit 0
fi

echo "$(date): 共发现 ${#IMAGE_ARRAY[@]} 个镜像需要打包。"
echo "---"

# 2. 循环遍历并打包每个镜像
for IMAGE in "${IMAGE_ARRAY[@]}"; do
    # 提取镜像名称和标签，用于生成文件名。
    # 格式化规则：将所有的 '/' 和 ':' 替换为 '-'
    FILENAME=$(echo "$IMAGE" | tr / - | tr : -).tar
    
    echo "打包: ${IMAGE} -> ${FILENAME}"
    
    # 执行 docker save 命令
    docker save -o "${SAVE_DIR}/${FILENAME}" "$IMAGE"
    
    # 检查上一个命令的退出状态
    if [ $? -eq 0 ]; then
        FILE_SIZE=$(du -h "${SAVE_DIR}/${FILENAME}" | awk '{print $1}')
        echo "✅ 打包成功，文件大小: ${FILE_SIZE}"
    else
        echo "❌ 警告：打包失败或镜像不存在: ${IMAGE}"
    fi
    
    echo "---"
done

echo "$(date): --- 🎉 所有镜像打包完成 ---"
